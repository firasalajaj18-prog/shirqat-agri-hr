# منظومة الموارد البشرية - شعبة زراعة الشرقاط 🌾

منظومة إلكترونية متكاملة لإدارة وسجلات موظفي ومنتسبي شعبة زراعة الشرقاط (مديرية زراعة صلاح الدين).

## 🚀 المميزات الرئيسية
1. **بوابة الموظف:**
   - الدخول بالاسم الثلاثي ورمز الدخول العام.
   - ملء الاستمارة الوظيفية والبيانات الشخصية.
   - رفع أو التقاط صور المستمسكات الثبوتية بوجهيها (الأمامي والخلفي):
     - هوية الموظف (وجه أمامي + وجه خلفي)
     - البطاقة الوطنية الموحدة (وجه أمامي + وجه خلفي)
     - بطاقة السكن (وجه أمامي + وجه خلفي)
     - الصورة الشخصية الحديثة
     - صورة الفحص الطبي المعتمد

2. **بوابة المدير ولوحة التحكم:**
   - استيراد أسماء الموظفين مباشرة من ملفات Excel (`.xlsx`, `.xls`) مع كشف ذكي للأعمدة.
   - تصدير فوري مباشر لملف Excel منسق بالكامل.
   - تصدير فوري مباشر لملف Word (`.docx`) رسمي.
   - إيعاز الحفظ والتصدير التلقائي في مجلد مؤرخ (`تصدير_YYYY-MM-DD_HH-mm`) يشمل الجداول ومجلدات الصور لكل موظف.
   - إدارة كاملة للموظفين (بحث، تصفية، تعديل، حذف).
   - ميزة إفراغ وحذف كافة البيانات وإعادة تصفير المنظومة بأمان.

3. **دعم كامل لكافة الأجهزة:**
   - تصميم متجاوب يعمل بسلاسة على الهواتف الذكية والأجهزة اللوحية والحواسيب.
   - كاميرا مدمجة لالتقاط الصور والوثائق مباشرة من الهاتف أو اللابتوب.
   - قسم دعم فني ومساعدة مباشر للمنتسبين (اتصال هاتفي وواتساب).

## 🛠️ التشغيل محلياً
```bash
# تثبيت الحزم
npm install

# تشغيل الخادم
npm start
```
الموقع سيعمل على الرابط: `http://localhost:3000`
